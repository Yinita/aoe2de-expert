# 帝国研习社 · AoE2 DE Expert Academy

面向高水平《帝国时代 II：决定版》玩家的中文进阶训练站。采用原创卡通 SVG 战术插画与响应式卡片界面，覆盖单挑决策、群局协同、职业资料阅读和结构化复盘。目前收录 **32 个来源、24 张深度训练卡**，其中 15 个来源发表于 2026 年。

## 使用

- **单挑实验室**：按主题与地图筛选训练卡，查看适用条件、执行步骤、刻意练习、复盘指标及原始资料。
- **群局战术室**：切换 Flank / Pocket / 贸易战术示意，练习集结、支援与共同决策。
- **专家资料库**：收录职业选手、工具作者与官方资料，支持关键词检索与收藏。
- **录像复盘台**：手动记录证据、决策与下一次行动，导出 Markdown 复盘档案。
- **我的训练计划**：四周十二项练习，支持打卡与自选专项清单。
- **免密码用户切换**：按昵称建立用户，选择单挑、群局或综合方向，每人独立保存收藏、训练和复盘。已有 v1 数据自动迁移至默认档案。
- **Google Drive 同步入口**：配置管理员部署的 Apps Script 地址与共享密钥后，可刷新云端用户目录、自动同步、离线保留修改和处理版本冲突。可复制内测同步链接到另一台设备。

默认使用浏览器 `localStorage`。连接云端后，档案同步至管理员 Drive 内的本项目 JSON 文件；同一内测房间的成员可以直接切换并读写所有用户，不进行个人身份验证。当前仓库只提供云端源码与接入界面，**尚未部署真实 Apps Script 服务**。管理员部署步骤见 [cloud/README.md](cloud/README.md)，后端见 [cloud/Code.gs](cloud/Code.gs)。

复盘台不解析录像文件。重要笔记可导出 Markdown。切换用户不会改变其他设备当前选择的用户；同步冲突保留本地记录，由使用者选择保留副本或载入云端。

## 本地预览

无需安装依赖，无需构建：

```bash
python3 -m http.server 8188
```

打开 `http://localhost:8188`。部署时保留相对资源路径，可直接部署到 GitHub Pages 的仓库子路径。

## GitHub Pages

仓库设置 → **Pages** → **Build and deployment**：

1. Source 选择 **Deploy from a branch**。
2. Branch 选择 **main**，目录选择 **/ (root)**，点击 **Save**。
3. 在 Actions 中等待 GitHub 自带的 Pages 构建完成。

预期网址：`https://yinita.github.io/aoe2de-expert/`。只有构建成功并且该地址返回页面后，才代表部署完成。

仓库根目录包含 `.nojekyll`，无需 Jekyll 或自定义构建工作流。

## 内容与版本

来源与训练内容集中在 `data.js`，页面逻辑在 `app.js`，同步模块在 `cloud-sync.js`，样式在 `styles.css`。资料库按发布日期排序，支持年份筛选；持续维护的工具不以核验日期冒充发布日期。更新资料时应核对原作者页面、发布日期、版本与适用场景，不将预览版（PUP）当作正式版。资料核验日期为 **2026-11-16**；已核验的正式版参考是官方 **Update 188329（2026-10-27）**，不承诺自动追踪更新。

训练卡是本站根据所列一手资料整理的训练设计，不是职业选手原话，也不表示选手背书。训练指标用于自我对比，不是职业评级。外部工具的价格、功能及可用性，以原站当前说明为准。

插画为本项目原创 SVG，不使用游戏截图或选手肖像。本站是独立社区项目，与 Microsoft、World’s Edge 或原资料作者无隶属关系。《Age of Empires》及相关商标归其各自权利人所有。
